# AI-новости

Персональный Telegram-бот [@vadikAI291293bot](https://t.me/vadikAI291293bot).
Работает в отдельном Supabase-проекте «AI-новости», ref `xdcqjzaceraigcgwglff`,
регион Ireland. Проект «moya-istoriya» не используется ботом.

## Что умеет

- Проверяет источники каждые 15 минут и присылает только важные новые события.
- В уведомлении есть краткое объяснение пользы, следующее действие и ссылка на статью.
- Приоритет: Gemini/Veo, Grok/xAI, заявления Илона Маска об AI и инструменты
  генерации видео: Sora, Runway, Luma, Kling, Pika.
- Отвечает на текстовые вопросы в привязанном личном Telegram-чате:
  объясняет новости, помогает выбирать инструменты и писать промпты.
- Учитывает последние четыре пары сообщений. Завершённые записи переписки
  удаляются из базы через 30 дней.
- Не генерирует видео и не обрабатывает голосовые сообщения. Общение использует
  ограниченную подборку сохранённых новостей и проверенных ссылок,
  без живого поиска по всему интернету. Свежие цены и доступность нужно
  проверять на сайте инструмента.

В Telegram доступны `/help`, `/status`, `/pause`, `/resume`.
Пауза останавливает уведомления о новостях; общаться с ботом по-прежнему можно.

## Источники

Подключены девять источников:

1. OpenAI — официальная RSS-лента.
2. Google AI — официальная RSS-лента.
3. Hugging Face — официальный блог.
4. Gemini — официальная лента Google, включая Veo.
5. xAI — публикации xAI через Google News; прямой сайт блокирует серверное чтение.
6. Runway — официальные исследовательские публикации.
7. Luma — официальные новости.
8. Илон Маск и AI — Reuters, TechCrunch, The Verge через Google News.
9. AI-видео — обзоры и новости Creative Bloq, The Verge, TechCrunch через Google News.

Ленты СМИ дополнительно фильтруются по домену издателя. Это не чтение каждого
сообщения Маска в X и не полный охват всех выступлений. Ссылки Google News
открывают публикации соответствующего источника. Временная ошибка одного источника
не останавливает остальные; следующая проверка повторяет чтение.

Прежние публикации при подключении источника помечаются как история, чтобы
не завалить чат архивом. Новости старше 48 часов не отправляются. Повторы
удаляются по ссылке и идентификатору события. Модель должна подтвердить оценку
важности фрагментом исходной новости; маркетинговое «лучший» не считается рейтингом.

## Модель и лимиты

Groq `qwen/qwen3.8-27b`, reasoning отключён. Ключ бесплатного аккаунта сохранён
в Edge Functions Secrets. Подписка ChatGPT не используется этим ботом.

Новости и общение делят локальный бюджет 100 000 токенов и 80 запросов за сутки UTC.
Перед запросом атомарно резервируется верхняя оценка расхода; завершённые запросы
учитываются по реальному ответу провайдера. При неизвестном расходе сохраняется резерв.
Чтение лент и команды не вызывают модель. За проверку модель оценивает максимум две
новые публикации. Лимиты бесплатного провайдера могут измениться; при HTTP 429
обработка откладывается, без автоматической покупки платных запросов.

## Код

- `function/worker.mjs` — чтение источников, отбор и отправка новостей,
  защищённые действия настройки и Telegram webhook.
- `function/core.mjs` — разбор RSS, приоритеты, проверка решения модели,
  текст новостного уведомления.
- `function/adapters.mjs` — чтение официальных страниц Runway и Luma.
- `function/chat.mjs` — вопросы, память диалога, команды и каталог ссылок.
- `function/index.ts` — запуск функции на Supabase.
- `setup.sql`, `schedule.sql`, `expand.sql`, `extra-feeds.sql` —
  сохранённые настройки базы и расписания. Они уже применены;
  не запускать начальный `setup.sql` повторно.
- `tests/` — проверки обработки новостей, безопасности, лимитов и общения.

В Supabase код открыт в Edge Functions → ai-news-monitor → Code.
Локальные исходники не содержат ключей, пароля базы или номера личного чата.

## Работа на сервере и доступ

Мониторинг включён 9 октября 2026, 23:18 по Москве.
Telegram webhook принимает только сообщения владельца из привязанного личного
чата и проверяет отдельный секрет Telegram. Повтор одного update_id игнорируется.
Ответ обрабатывается в фоне через EdgeRuntime.waitUntil; резервное расписание
каждую минуту подхватывает очередь, если фоновая обработка прервалась.

Таблицы закрыты для anon и authenticated: RLS включён, права есть только у серверной роли.
Отсутствие пользовательских политик здесь намеренное. Сообщение
[RLS Enabled No Policy](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)
уровня INFO соответствует этому режиму доступа.

Значения `GROQ_API_KEY` и `TELEGRAM_BOT_TOKEN` хранятся только в Edge Secrets.
Административные запросы требуют `x-news-token`, исходное значение хранится в Vault
как `ai_news_scheduler_token`. Telegram использует другой секрет. JWT-проверка
платформы отключена, поскольку функция сама проверяет эти ключи.

При неоднозначном результате отправки сообщение помечается uncertain и автоматически
не пересылается: оно уже могло дойти до Telegram. Такие случаи требуют проверки.
