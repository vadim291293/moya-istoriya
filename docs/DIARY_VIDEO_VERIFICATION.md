## Реализовано

- «Записи»: первые слова, новые умения, смешные фразы, тёплые моменты. Старые текстовые `note` без категории показываются в тёплых моментах. Обычные фото/видео с NULL категорией не включаются в дневник и не переименовываются.
- Создание: раздел → подсказка достижения → ребёнок → текст/дата → необязательные вложения только для нового умения. Обычная медиазагрузка сохраняет прежний путь. Фильтр ребёнка передаётся форме, единственный ребёнок выбран заранее; «Вся семья» означает отсутствие личной отметки.
- Карточка раскрывает полный текст и все вложения. Просмотр медиа/правка используют прежние защищённые компоненты. Чужая семейная запись читается без предоставления прав редактора.
- Новое вложение загружается один раз; дневник и Фото/Видео показывают ту же metadata-запись. Повтор после неизвестного ответа использует прежние UUID/категорию/файлы. Привязка уже загруженного архива к другой записи не реализована: повторный выбор файла телефона создаёт новую загрузку.
- Настоящие кадры видео: SDK 57 `generateThumbnailsAsync`, один неиграющий извлекатель в активном списке, таймаут 8 секунд, memory-only cache до 16 кадров. Фон/blur/unmount отменяют очередь и освобождают извлекатель. Web/ошибка/неподдерживаемый кодек дают честную заглушку, не запрещая просмотр. Название строки показывается только если сохранено; chevron убран.
- Плеер: `nativeControls=false`, небольшие play/pause, touch/drag seek, время, закрытие и отдельная правка. Нет системных стрелок/шестерёнки/крупной кнопки поверх лица. Нижние controls скрываются через 3 секунды воспроизведения, возвращаются по касанию; при паузе видны. Прежние guards останавливают видео при фоне/blur/Back/закрытии и отвергают поздние действия.
