Добавлены 18 локальных тестов `tests/auth-provider.test.cjs`, запускающих production-компонент через существующий lightweight hook harness. Supabase и ответы запросов синтетические. Это не физический Android/iOS, не настоящая Auth-сессия и не проверка пароля владельца.

## Воспроизведено до исправления

Первый запуск 14 сценариев дал 8 отказов:

- поздний initial getSession мог перезаписать успешный ручной retry без отдельного auth event;
- более ранний retry мог заменить сессию, пока более новый ещё ожидал ответа;
- удержанный refreshFamily старого аккаунта мог начать новые чтения и обновить семейный state;
- удержанный guest refresh мог поставить idle после уже принятого входа;
- старый выбор семьи мог начать загрузку после смены аккаунта;
- старый logout мог вызвать signOut для нового аккаунта;
- одновременные logout вызывали SDK дважды;
- очереди auth/retry могли обновить state после размонтирования Provider.

Исправление сохранило AuthProvider, запросы к существующим таблицам и защищённую маршрутизацию. Добавлены проверки времени жизни Provider и текущего userId для семейных методов; начальное восстановление и retry используют общую revision; logout проверяет пользователя после асинхронного preflight и объединяет повторные вызовы одного аккаунта в один запрос. В auth callback нет асинхронных SDK-вызовов.

## Подтверждено локально после исправления

- Восстановление сессии, собственные family_members → families → children; один подписчик.
- Auth event имеет приоритет над поздним initial restore; новый retry — над прежним retry/restore.
- Поздние ответы каждого семейного запроса, удержанные старые обработчики и быстрый выбор семьи не заменяют новые семейные данные.
- Ошибка прав/чтения не превращается в ветку setup; setup открывается только при успешном пустом членстве. Несколько членств требуют допустимого выбора.
- Logout локальный и single-flight; старый аккаунт и смена пользователя во время preflight не вызывают logout нового. Ошибка preflight сохраняет сессию и позволяет повторить действие.
- Размонтирование отключает подписку и игнорирует очереди; refresh токена того же пользователя сохраняет загруженную семью без лишнего чтения.
- Полный `npm test`: 91/91. `npm run typecheck`: успешно.
- Android JS/Hermes export: 1758 модулей, 4,7 МБ, `artifacts/android-auth-provider-afc59e15` во внешней рабочей папке Codex. Это не APK.
