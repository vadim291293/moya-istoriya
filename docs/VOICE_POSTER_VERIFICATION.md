## Что изменилось

- Список видео показывает загрузку настоящего кадра, а не постоянную безымянную плитку. Native SDK получает массив времён; при проблеме выбранного кадра пробуется первый. При сбое streaming extraction используется ограниченная временная локальная копия. После неудачи есть понятный статус и повтор обложки; просмотр ролика остаётся доступным.
- «Голос на память» — необязательное вложение в первых словах, умениях, смешных фразах и тёплых моментах. Записать, остановить, прослушать, убрать из черновика, сохранить вместе с текстом. Один голос, до 3 минут/5 МиБ; общий лимит пять вложений. Фото/видео по-прежнему только в новых умениях.
- Голос имеет отдельный audio media type, не попадает в Фото/Видео и открывается из дневника в простом окне прослушивания. Текст дневника обязателен; голос не подменяет заметку. Редактор и восстановление из корзины сохраняют файл.
- Добавлен только `expo-audio@57.0.5`. Он поддерживается текущим SDK 57 и Expo Go. Микрофон запрашивается только по кнопке; ImagePicker больше не исключает Android RECORD_AUDIO. Камера, фоновые audio services/recording/playback выключены. Настройки Windows/VPN и работающий Metro не менялись.

## Границы безопасности и совместимость

Существующий account/family-bound upload, durable submission и reconcile по тому же UUID переиспользуются. Потерянный ответ RPC не приводит к повторной загрузке или удалению потенциально сохранённого звука. Android picker journal сохраняет минимальные поля голоса без байтов и токенов; старые журналы совместимы. Неизвестная отправка имеет приоритет перед новым маршрутом/категорией.

Запись микрофона сериализована: двойной тап не создаёт две записи; поздние permission/prepare после ухода не включают микрофон; фон останавливает запись, уход/смена аккаунта запрещают позднее прикрепление. Save и запуск выбора визуальных файлов блокируются синхронно. Аудиоплеер только для выбранного файла/черновика; close немедленно ставит pause и отключает дальнейший play. Нет автозапуска/фонового воспроизведения; development effect replay проверен отдельно.

Видеоизвлечение — один extractor за раз, очередь с timeout 20 секунд и cache до 16 native references. Локальный fallback только HTTPS, до 50 МиБ, уникальный путь в приватном cache. Старый remote player освобождается перед local player. Отмена, завершение и ошибка удаляют только созданный этой операцией временный файл; фон/смена scope прекращают работу. Никакой новой metadata/Storage-записи обложки, публичной ссылки или экспорта в библиотеку телефона.

## Что не доказано этими проверками

- Настоящий microphone/permission UI, AAC codec/длительность, audio upload через HTTP и playback именно на устройстве. Серверный rollback создаёт metadata, не загружает аудиобайты и не воспроизводит JWT/Storage HTTP целиком. Тесты используют mocks и не доказывают Android process-death.
- Реальный кадр конкретного ролика владельца: исходная ошибка native extraction не была прислана. Массив времён и local fallback устраняют вероятные причины, но это не доказательство единственной причины. Недоступный/истёкший URL, необычный кодек, медленная сеть и timeout всё ещё могут не дать кадр. Повтор и просмотр доступны; на web native extraction не заявляется.
- Local fallback скачивает ролик целиком, значит может тратить до 50 МиБ трафика на попытку. Timeout/отмена ограничивают работу, но не обещают кадр при любой сети. Настоящая постоянная backend-генерация poster позже потребует отдельного решения/хранилища.
- Временный poster удаляется при нормальном lifecycle. Crash/kill может оставить private cache до очистки ОС. Несохранённые recording drafts тоже остаются в private app cache до обычной очистки; отдельного сборщика/универсального автосохранения черновиков нет. Не очищать пользовательские данные автоматически.
- 3 минуты ограничены recorder/UI, не серверным анализом duration/codec. 5 МиБ проверяются по фактическим байтам в клиенте и metadata CHECK; bucket имеет общий, не per-MIME лимит 50 МиБ. Сервер не подтверждает истинный размер/формат содержимого по metadata. Это не новая защита от злонамеренного клиента/квот и не антивирус.
- Приватность после отзыва доступа сохраняет прежнее ограничение: выданный signed URL не отзывается мгновенно. Корзина не заменяет backup и долговременную стратегию семейного архива.
