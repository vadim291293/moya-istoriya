## Чего результат не подтверждает

- Работу интерфейса, Expo Go, физического Android/iOS, EXIF picker, нативного видео или письма восстановления пароля. Это отдельные сценарии `SMOKE_TEST.md`.
- Успешный повторный вход именно владельца: ранее сервер отказал с `invalid_credentials`; его пароль не читали и не меняли.
- Совместный доступ родственников внутри одной семьи и разрешения будущих ролей. Проверены два независимых владельца разных семей.
- Глобальное ограничение на одно семейное членство: идемпотентность setup не заменяет такое ограничение БД.
- Нативное восстановление сессии после перезапуска или сбой сети во время настоящей отправки.

Не запускать скрипт снова автоматически: каждый запуск создаёт ещё два аккаунта и новые данные. Нужны новое точное разрешение владельца и проверка целевого проекта. Очистка этого набора также требует отдельного согласования; текущий запуск её не выполнял.

## Дополнительная read-only проверка children

7 октября 2026 в SQL Editor того же проекта выполнен только SELECT системных каталогов по `supabase/checks/children_metadata_readonly.sql`. Новые строки/политики/права не создавались. Подтверждены:

- `id uuid NOT NULL DEFAULT gen_random_uuid()`, первичный ключ;
- `family_id uuid NOT NULL`, FK на `families(id) ON DELETE CASCADE`;
- `name text NOT NULL`, `birth_date date NOT NULL`;
- `photo text NULL`, `created_at timestamptz NOT NULL DEFAULT now()`;
- RLS включён (`forced=false`), пользовательских триггеров children нет;
- роль authenticated имеет табличные SELECT/INSERT/UPDATE/DELETE grants. Наличие grant не заменяет RLS: обнаружены только политики SELECT и INSERT для authenticated с проверкой членства текущего `auth.uid()` в `children.family_id`. UPDATE/DELETE-политик в полученном списке нет;
- INSERT доступен участнику своей семьи; условие роли владельца в существующей политике отсутствует.

Этого достаточно для разработки добавления ребёнка без изменения БД, но это не сквозной тест новой формы и не новая authenticated INSERT-проверка. Дополнительные тестовые пользователи/дети здесь не создавались.
